صنّف مخاطر الائتمان باستخدام استخراج الميزات الكمية Rimay من Kipu Quantum

ملاحظة

دوال IBM Quantum® Functions ميزة بيتا متاحة فقط لمستخدمي IBM Quantum Premium Plan وFlex Plan وOn-Prem (من خلال IBM Quantum Platform API) Plan. ميزات بيتا قابلة للتغيير.

تقدير الاستخدام: دقيقتان على معالج Nighthawk r2. (ملاحظة: هذا تقدير فقط. قد يختلف وقت التشغيل لديك.)

نتائج التعلم​

  • جهّز بيانات جدولية بأعمدة فئوية ورقمية لدالة Rimay الكمومية.

  • اضبط تعيين ميزات كمية على بيانات التدريب وعيّن بيانات الاختبار في التشغيل نفسه.

  • درّب نماذج كلاسيكية على الميزات المحوّلة كميًا، منفردةً ومدمجةً مع الميزات الأصلية.

  • قارن النتائج بخط أساس كلاسيكي بحت.

المتطلبات المسبقة​

قبل أن تبدأ هذا الدرس، يُفضّل أن تكون على دراية بالمواضيع التالية:

  • مقدمة إلى Functions

  • التصنيف الخاضع للإشراف مع scikit-learn

الخلفية​

كثير من مسائل تعلّم الآلة في الصناعة تتعامل مع مجموعات بيانات جدولية صغيرة أو متوسطة الحجم، حيث لا يمكن إضافة بيانات أكثر وتتوقف دقة النموذج عن التحسّن. تقييم مخاطر الائتمان مثال نموذجي على ذلك. فالمُقرِض يستخدم بضع عشرات من السمات ليقرر ما إذا كان المتقدّم سيسدّد القرض على الأرجح.

تضيف Rimay من Kipu Quantum خطوة معالجة مسبقة كمّية إلى خط معالجة كهذا. وهي تنفّذ خوارزمية استخلاص الميزات الكمّية المضادة للاديباتية المرقمنة [1]. تُربط كل ميزة مدخلة بكيوبت واحد. وتحدد قيم الميزات والمعلومات المتبادلة بينها الحقول المحلية والاقترانات في هاميلتوني من نوع الزجاج الدوراني. بعد ذلك تُطوِّر الديناميكيات المضادة للاديباتية النظام الكمّي نحو حالاته منخفضة الطاقة، وتصبح القيم المتوقعة أحادية وثنائية الجسيم المقاسة في النهاية هي الميزات الجديدة المحوّلة كمّيًا. تلتقط هذه الميزات الارتباطات غير الخطية بين المدخلات، ويمكنك تمريرها إلى أي نموذج كلاسيكي.

يستخدم هذا الدرس مجموعة بيانات الائتمان الألمانية من OpenML [2]، وتضم 1000 متقدّم و20 سمة، لتدريب مصنّف الغابة العشوائية. ستبدأ بإنشاء خط أساس كلاسيكي، ثم ترسل البيانات إلى Rimay، وأخيرًا تدرّب النوع نفسه من النماذج على الميزات المحوّلة كمّيًا، سواء وحدها أو مدمجة مع الميزات الأصلية.

def train_random_forest(x, y, n_estimators, max_depth):
    """Train a random forest classifier with fixed hyperparameters."""
    model = RandomForestClassifier(
        n_estimators=n_estimators,
        max_depth=max_depth,
        min_samples_split=5,
        min_samples_leaf=1,
        max_features="sqrt",
        random_state=42,
        n_jobs=-1,
    )
    return model.fit(x, y)

def evaluate(model, x, y):
    """Return the classification metrics of a trained model on a test set."""
    y_pred = model.predict(x)
    y_proba = model.predict_proba(x)[:, 1]
    return {
        "Accuracy": accuracy_score(y, y_pred),
        "AUC": roc_auc_score(y, y_proba),
        "F1 score": f1_score(y, y_pred),
        "Precision": precision_score(y, y_pred),
        "Recall": recall_score(y, y_pred),
    }

حساب حجم الدالة​

تعمل كل مهمة بحجم دالة هو S أو M أو L، وهو يحدد موارد الحوسبة التي تعمل عليها. بالنسبة إلى Rimay، يعتمد الحجم على عدد الصفوف التي تربطها المهمة، من صفوف التدريب والاختبار معًا. إذا طلبت حجمًا أصغر من اللازم، تفشل المهمة بالخطأ 4600. لمعرفة الأحجام وحدودها، راجع أحجام الدوال في دليل Rimay.

تعرّف الخلية التالية حاسبة الحجم. وهي تعمل على جهازك، وتقرأ فقط البيانات التي تمررها إليها، ولا ترسل أي شيء.

from os import PathLike
from typing import Any, Literal, Sequence, Sized

Size = Literal["S", "M", "L"]

# Upper bounds (inclusive) in samples.
_SMALL = 2_999
_MEDIUM = 9_999

FIT_TRANSFORM, TRANSFORM, DELETE = "fit-transform", "transform", "delete"

# Which positions of input_file hold samples, per mode. The labels in
# y_train submit no circuits of their own, so they are not counted.
SAMPLE_POSITIONS = {FIT_TRANSFORM: (0, 2), TRANSFORM: (0,)}

def calculate_function_size(problem: Sequence[Sized], **kwargs: Any) -> Size:
    """Return the size ("S", "M" or "L") required to run the function."""
    metrics = _measure(problem, **kwargs)
    if _is_small(metrics):
        return "S"
    if _is_medium(metrics):
        return "M"
    return "L"

def _measure(problem: Sequence[Sized], **kwargs: Any) -> dict:
    """The samples the job submits."""
    return {"samples": count_samples(problem, kwargs.get("mode"))}

def count_samples(problem: Sequence[Sized], mode: Any) -> int:
    """Rows across the data sets of ``problem`` that carry samples."""
    if mode == DELETE:
        return 0
    if mode not in SAMPLE_POSITIONS:
        raise ValueError(f"cannot size mode {mode!r}")
    if _is_name(problem) or (
        isinstance(problem, (list, tuple))
        and any(_is_name(data) for data in problem)
    ):
        raise TypeError(
            "pass the data, not the file name: read each input_file, e.g. with "
            "pandas.read_csv, and pass the data sets in input_file order"
        )
    if not isinstance(problem, (list, tuple)):
        raise TypeError(
            "pass a list of data sets in input_file order, e.g. [x_train, y_train], "
            f"not a single {type(problem).__name__}"
        )
    return sum(
        len(problem[i]) for i in SAMPLE_POSITIONS[mode] if i < len(problem)
    )

def _is_name(value: Any) -> bool:
    """A file name or path rather than data."""
    return isinstance(value, (str, bytes, PathLike))

def _is_small(metrics: dict) -> bool:
    """Determine if the metrics fit T-size 'S'."""
    return metrics["samples"] <= _SMALL

def _is_medium(metrics: dict) -> bool:
    """Determine if the metrics fit T-size 'M'."""
    return metrics["samples"] <= _MEDIUM

مرّر مجموعات البيانات بنفس ترتيب الملفات في input_file، مع نمط التشغيل:

    [x_train, y_train, x_test], mode="fit-transform"

تنزيل الميزات المحوّلة كمّيًا​

نزّل الملفات التي كتبتها المهمة، باستخدام الأسماء الموجودة في output_files. يبدأ كل اسم بمعرّف المهمة، فتبقى ملفات هذا التشغيل متاحة بعد التشغيلات اللاحقة. مرّر target_name ليُحفظ كل ملف باسمه الخاص.

train_file, test_file = result["output_files"]

xq_test = pd.read_csv(test_file).to_numpy()

التدريب على الميزات المحوّلة كمّيًا​

quantum = train_random_forest(
    xq_train, y_train, n_estimators=900, max_depth=15
)
results["Quantum"] = evaluate(quantum, xq_test, y_test)

التدريب على الميزات الكلاسيكية والكمّية معًا​

ضمّ الميزات الأصلية والميزات المحوّلة كمّيًا معًا، ودرّب النموذج نفسه على المجموعة المدمجة.

xh_train = np.hstack([x_train.to_numpy(), xq_train])
xh_test = np.hstack([x_test.to_numpy(), xq_test])

hybrid = train_random_forest(
    xh_train, y_train, n_estimators=900, max_depth=15
)
results["Hybrid"] = evaluate(hybrid, xh_test, y_test)

الخاتمة​

ما أنجزته​

في هذا الدرس، أنجزت ما يلي:

  1. أعددت مجموعة بيانات واقعية لمخاطر الائتمان بسمات فئوية وعددية لاستخلاص الميزات الكمّية.

  2. أنشأت خط أساس كلاسيكيًا بالغابة العشوائية.

  3. استخدمت Rimay لتعلّم ربط ميزات كمّي على عتاد كمّي، وربطت مجموعتي التدريب والاختبار في تشغيل واحد.

  4. درّبت النموذج نفسه على الميزات المحوّلة كمّيًا وعلى الميزات المدمجة، وقارنتها بخط الأساس.

أهم الاستنتاجات​

  • تندمج Rimay في خط معالجة تعلّم آلة قائم كخطوة معالجة مسبقة إضافية واحدة. وتحتفظ بإعداد بياناتك ونموذجك الكلاسيكي.

  • عدد الكيوبتات يحدّ من عدد الميزات المدخلة، وعدد الصفوف مضروبًا في shots يحدّ من حجم المهمة الواحدة.

  • استخدم الميزات المحوّلة كمّيًا مدمجة مع الميزات الأصلية كخيار افتراضي، لأن النموذج يستطيع الاستفادة منهما معًا.

الخطوات التالية​

التوصيات
  • اقرأ دليل Rimay لتتعرف على كل المدخلات، وتربط بيانات جديدة باستخدام mode="transform"، وتطّلع على مزيد من الاختبارات المرجعية.
  • اقرأ كيف طُبّق استخلاص الميزات الكمّي على تصنيف صور الأقمار الصناعية [3].
